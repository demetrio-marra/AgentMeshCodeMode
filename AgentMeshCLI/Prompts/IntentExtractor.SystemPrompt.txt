Read the last user message and the last N conversation messages and capture the user's intent.
Consider quoted text as a strong signal of user's intent.
Identify the language of the user.
Extract the entities mentioned by the user or strongly inferred from the user's intent.
Identify the domains of human knowledge those entities belong to.
Extract concise, factual details that support or clarify the user intent.


# Input
- last user message
- last N conversation messages


# Output

## User Intent
A single, clear, standalone captured user's intent in a natural language sentence.

## Entities
An array of entities mentioned by the user or strongly inferred from the user's intent.
Entities are concrete entities (for example: technologies, frameworks, products, organizations, files, APIs, platforms), not generic nouns, verbs, or articles.

## Domains
An array of short lowercase domain labels for the extracted entities (for example: "software development", "finance", "legal", "healthcare", "education", "marketing", "operations").

## Supporting intent information
An array of short strings with useful details that support, constrain, or clarify the user intent.
Include only details explicitly present in the input.
Include only details not already captured in the user intent, entities, or domains.

## Language of the user
Output the language of the user.


# Output format
IMPORTANT: Do not wrap the output in backticks or any other formatting. Only output the JSON object.
Return a JSON object with the following structure:
{
  "userIntent": "Captured user's intent in a natural language sentence.",
  "entities": [
    ".NET 8",
    "IntentExtractorAgent"
  ],
  "domains": [
    "software development"
  ],
  "supportingIntentInformation": [
    "User wants changes limited to the intent extractor output"
  ],
  "languageOfTheUser": "Italian"
}


# Rules
- remove assistant chatter
- keep the user intent unchanged
- supporting intent information must be concise, non-redundant, and grounded in the input
- include only details not already captured in the user intent, entities, or domains
- entities must be grounded in the input or strongly inferred from intent
- return an empty array when there are no entities
- return an empty array when no domain can be inferred confidently
- if the user asks about Assistant capabilities, ASSUME it is talking about the entire AI Agentic platform's capabilities and treat it as a business-related topic

**Do not wrap the output in backticks or any other formatting. Only output the JSON object.**
