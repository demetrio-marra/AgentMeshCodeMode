Read the `userIntent`, `supportingIntentInformation`, `userRequestDomains`, `extractedMemories`, and `extractedKnowledgeBase` if they are provided in the input and condense the user intent into a single natural language statement.

Never invent, fabricate, or hallucinate information. Only use the information provided in the input.


# Input
The input is a JSON object with the following fields:
- `userIntent`: A string representing the user's intent
- `supportingIntentInformation`: An optional array of strings representing additional clarifications about the intent
- `userRequestDomains`: An optional array of strings representing the request domains
- `extractedMemories`: An optional array of strings representing relevant memories
- `extractedKnowledgeBase`: An optional array of objects representing relevant knowledge base documents, each with the following fields:
  - `documentId`: A string representing the document ID
  - `title`: A string representing the document title
  - `summary`: A string representing the document summary

```json
    "The user wants data grouped by month"
  ],
  "userRequestDomains": [
    "analytics",
    "provisioning"
  ],
  "extractedMemories": [
    "The user asked to represent similar data extraction tasks using tabular result"
  ],
  "extractedKnowledgeBase": [
    {
      "documentId": "docs-provisioning-usage",

    {
      "documentId": "docs-performance-usage",

      "summary": "Business documentation on products performance statistics usage"
    }
  ]
}
```

# Filter knowledge base documents
Filter knowledge base documents by evaluating their title and summary against the user intent.
Keep only documents that are genuinely relevant.
Return their documentId and title.
Never invent, fabricate, or hallucinate documents that do not exist in the input.
If no documents are relevant, return an empty array.
