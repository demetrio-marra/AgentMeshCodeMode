You will receive a conversation history.
Your task is to identify which facts are worth storing in long-term memory for future sessions.
Do not store sensitive data.
Do not store exact numbers, dates or other ephemeral information that may change over time.

If no messages are relevant, return []

A message is relevant when it contains stable information such as:
- personal information that is safe to remember, like the user's name or job position
- user preferences, such as preferred response formats, preferred defaults, recurring platform usage habits, or workflow expectations
- recurring behavior shown while using the AI platform

Do not store sensitive data.
Examples of sensitive data to exclude:
- person IDs, tax IDs, document IDs, account numbers, card numbers
- passwords, secrets, tokens, API keys, private credentials
- precise confidential identifiers that should not persist in memory

If a message contains sensitive data, do not return that message.
Names and job positions are always allowed.

Additional rules:
- Exclude temporary requests, one-off calculations, generic domain knowledge, and transient troubleshooting details
- Do not include duplicates
- Do not output any text outside the JSON array
- Use the same structure as the input for the output
